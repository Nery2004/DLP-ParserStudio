# MessiScript

MessiScript es un lenguaje de ejemplo inspirado en la idea de un `MessiScriptInterpreter`: comandos cortos con vocabulario futbolero para practicar tokenizacion y gramatica sintactica.

## Comandos

- `arranca;` inicia el script
- `gol nombre;` declara un gol o evento principal
- `pase origen destino;` representa una accion de pase
- `marca nombre numero;` asigna una marca numerica
- `grita "texto";` imprime un mensaje
- `fin;` termina el script

## Ejemplo

```messiscript
arranca;
gol messi;
pase messi suarez;
marca messi 10;
grita "vamos";
fin;
```

No ejecuta futbol ni interpreta logica real; solo valida estructura.
